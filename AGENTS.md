# Repository navigation

- Read `rep_map.md` before exploring or modifying the project. Use its feature paths to narrow reads and searches instead of re-indexing the whole repository.
- Read `../projects_overview.md` for BOS/BAS integration work and update it when shared contracts or project relationships change.
- After every change, review `rep_map.md` and update affected paths, responsibilities, routes, data flows, configuration, commands, or verification notes as needed. Make the map update part of the same task; no edit is necessary when its contents remain accurate.
- Keep the map concise and factual. Record source paths and useful symbols, not copied source code, credentials, generated output, or a running activity log. Verify details in the relevant source before changing behavior.
